# RoboCheck

RoboCheck is a command-line pre-run diagnostic utility for mobile robots.

The project aims to provide a structured way of checking important robot
components before deployment and identifying conditions that may make a
robot unsafe or unreliable to operate.

## Planned Checks

- Battery health
- Motor status
- Sensor health
- Emergency stop
- Overall robot readiness

## Development

This project is being developed incrementally using Git for version
control, branching, testing and release management.
